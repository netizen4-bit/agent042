# Security Policy

## Supported Versions

We are committed to providing a secure and trusted foundation for your outbound lead generation and agentic workflow needs. 

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for our autonomous terminal agents. If you discover a vulnerability, we would like to know about it so we can take steps to address it as quickly as possible.

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them by reaching out directly to the repository maintainer. We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. 

When reporting, please provide:
* A description of the vulnerability.
* Steps to reproduce the issue.
* The version of the agent and Termux you are using.

Thank you for helping us keep this agentic tool secure and trusted!
